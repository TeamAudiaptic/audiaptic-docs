## Server

### Liam (@shackhorn)

💥 **Breaking change** The portal and API now require a password, and the performer websocket requires a token. The Max team should use `dev` passed to the token query param when testing locally. Audience devices should still connect without one. [#60](https://github.com/TeamAudiaptic/audiaptic-server/pull/60)

✨ **Feature** Production server auto-deployment is now active. The server redeploys from `main` every night at midnight Eastern, and on demand with the `audiaptic-redeploy` command on the server. [#60](https://github.com/TeamAudiaptic/audiaptic-server/pull/60)

✨ **Feature** A Discord webhook receives deployment updates from the production server.\ [#60](https://github.com/TeamAudiaptic/audiaptic-server/pull/60)

🔧 **Maintenance** Update Node from 20 to 24. [#60](https://github.com/TeamAudiaptic/audiaptic-server/pull/60)

🔧 **Maintenance** The production containers now run as unprivileged users instead of root. [#60](https://github.com/TeamAudiaptic/audiaptic-server/pull/60)
