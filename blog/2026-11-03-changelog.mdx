### Darren (@dcr8024)

💥 **Breaking change** Events now use `epochTimestamp` / `relativeTimestamp` with a `start` event instead of `execTimestamp`, matching the updated event docs [#43](https://github.com/TeamAudiaptic/audiaptic-client/pull/43)

✨ **Feature** Join a concert by code; the client downloads the concert's media listed in its R2 `index.json`, and deletes it on leave [#43](https://github.com/TeamAudiaptic/audiaptic-client/pull/43)

✨ **Feature** Image, audio and full-screen video events play downloaded assets, supporting `startOffsetMs`, `durationMs`, `loop` and fade-in [#43](https://github.com/TeamAudiaptic/audiaptic-client/pull/43)

✨ **Feature** Kahoot-style code entry home screen and a simplified concert screen with an image area and a compact event log [#43](https://github.com/TeamAudiaptic/audiaptic-client/pull/43)
