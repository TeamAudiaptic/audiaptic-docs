## Server

### Liam (@shackhorn)

✨ **Feature** The server now "understands" the difference between ``audio``, ``caption``, ``color``, ``haptic``, ``image``, ``ping``, and ``torch`` event types. Right now, only ``ping`` is truly "supported". [#25](https://github.com/TeamAudiaptic/audiaptic-server/pull/25)

✨ **Feature** The performer WebSocket is now documented with an AsyncAPI spec generated from the event schemas, synced to the docs site automatically. [#33](https://github.com/TeamAudiaptic/audiaptic-server/pull/33)

✨ **Feature** One-command local dev environment (`run_me.bat` / `teardown.bat`) that runs the portal and API behind Caddy, matching production URLs. Use `run_me.bat`. Only use `teardown.bat` if it gets stuck. [#33](https://github.com/TeamAudiaptic/audiaptic-server/pull/33)

🐛 **Fix** The generated OpenAPI spec was empty because routes were registered before Swagger loaded. [#33](https://github.com/TeamAudiaptic/audiaptic-server/pull/33)

🐛 **Fix** `npm run export:schema` failed on Windows. [#33](https://github.com/TeamAudiaptic/audiaptic-server/pull/33)

🔧 **Maintenance** Modified workflow file to generate an openapi spec json. [#25](https://github.com/TeamAudiaptic/audiaptic-server/pull/25)

🔧 **Maintenance** The docs sync workflow now also pushes `asyncapi.json`. Added `cross-env`. Build output (`dist/`) is now git-ignored. [#33](https://github.com/TeamAudiaptic/audiaptic-server/pull/33)
