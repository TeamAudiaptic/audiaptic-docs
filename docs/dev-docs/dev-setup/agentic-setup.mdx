# Agentic Setup

## VS Code
The suggested agentic development setup revolves around beginning chats within the audiaptic-docs repo while
adding the other project repos to the workspace. The AGENTS.md file of the docs repo will provide the agent
with base project and architecture context while routing the the necessary repos according to the task. 

### 1. Clone all the repos

The DAVHI project spans across these repos:
- Docs: [audiaptic-docs](https://github.com/TeamAudiaptic/audiaptic-docs)
- Max: [audiaptic-max](https://github.com/TeamAudiaptic/audiaptic-max)
- Client: [audiaptic-client](https://github.com/TeamAudiaptic/audiaptic-client)
- Server: [audiaptic-server](https://github.com/TeamAudiaptic/audiaptic-server)

### 2. Add all repos to a VS Code workspace

Open the audiaptic-docs folder in VS Code first. 

Starting from the docs repoClick File > Add folder to workspace and add each project repo to the workspace

### 3. Save the workspace

Click File > Save workspace as... and save the workspace. 

In the future, you can open the saved workspace easily. 

### 4. Work from the workspace

For any task which you want to use an AI agent for, you should be able to start a chat in the workspace 
and the agent will be able to work with proper project context. 

There are no instructions on branch naming, so create any branches ahead of time.
