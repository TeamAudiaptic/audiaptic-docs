# Start Event

A `start` event signals the start of a performace and determines the start time for all future `relativeTimestamps`.

```json
{
  "schemaVersion": "1.0",
  "eventId": "00000000-0000-0000-0000-000000000000",
  "sequence": 47,
  "type": "audio",
  "sentTimestamp": 1730000005000,
  "epochTimestamp": 1790000000000,
	"relativeTimestamp": 500,
  "payload": {
    "assetAlias": "low-drone.mp3",
    "startOffsetMs": 12000,
    "durationMs": 5000,
    "transitionMs": 0
  }
}
```

| Payload field | Type | Required | Description |
| --- | --- | --- | --- |
| `assetAlias` | string | Yes | Alias of a session-preloaded audio asset. |
| `startOffsetMs` | integer | No | Offset from the start of the asset. Defaults to `0`. |
| `durationMs` | integer | No | Clip length. When omitted, playback continues to the end of the asset. |
| `transitionMs` | integer | No | Time to fade in the audio. |
