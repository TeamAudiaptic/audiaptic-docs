# WebSocket API

This reference is rendered from `asyncapi/asyncapi.json`, which the server's `api-docs-sync` workflow generates from its implemented event schemas and synchronizes to this repository. The specification is the authoritative contract for the current performer WebSocket API.

The legacy event pages remain available for historical reference, but they are not synchronized with the server and must not be used to infer current schema behavior.
