# Image Event

An `image` event displays a preloaded visual asset, such as a PNG or PDF. The client determines how to render an image from its session manifest; Max sends only its alias.

```json
{
  "schemaVersion": "1.0",
  "eventId": "demo-image-1",
  "sequence": 46,
  "type": "image",
  "sentTimestamp": 1730000005000,
  "execTimestamp": 1730000005500,
  "payload": {
    "assetAlias": "example.jpg",
    "durationMs": 8000,
    "transitionMs": 0
  }
}
```

| Payload field | Type | Required | Description |
| --- | --- | --- | --- |
| `assetAlias` | string | Yes | Alias of a session-preloaded visual asset. |
| `durationMs` | integer | No | How long to display the asset. When omitted, it remains until replaced. |
| `transitionMs` | integer | No | Time to fade the image in. |
