# Asset Event

An `asset` event displays a preloaded visual asset, such as a PNG or PDF. The client determines how to render an asset from its session manifest; Max sends only its alias.

```json
{
  "schemaVersion": "1.0",
  "eventId": "score-page-01",
  "sequence": 46,
  "type": "asset",
  "timestamp": 1730000005000,
  "payload": {
    "assetAlias": "score-page-1",
    "durationMs": 8000
  }
}
```

| Payload field | Type | Required | Description |
| --- | --- | --- | --- |
| `assetAlias` | string | Yes | Alias of a session-preloaded visual asset. |
| `durationMs` | integer | No | How long to display the asset. When omitted, it remains until replaced. |
