# Haptic Event

A `haptic` event starts a continuous haptic response at a normalized intensity. The React Native client maps this intent to the native haptic implementation for the device.

```json
{
  "schemaVersion": "1.0",
  "eventId": "pulse-01",
  "sequence": 42,
  "type": "haptic",
  "timestamp": 1730000000000,
  "payload": {
    "intensity": 0.75,
    "sharpness": 0.4,
    "durationMs": 600
  }
}
```

| Payload field | Type | Required | Description |
| --- | --- | --- | --- |
| `intensity` | number | Yes | Normalized haptic strength. |
| `sharpness` | number | No | Normalized haptic character, from soft (`0`) to crisp (`1`). Clients without this capability may ignore it. |
| `durationMs` | integer | Yes | Length of the haptic response. |
