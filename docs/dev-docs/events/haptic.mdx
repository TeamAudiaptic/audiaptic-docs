# Haptic Event

A `haptic` event starts a continuous haptic response at a normalized intensity. The React Native client maps this intent to the native haptic implementation for the device.

```json
{
  "schemaVersion": "1.0",
  "eventId": "00000000-0000-0000-0000-000000000000",
  "sequence": 42,
  "type": "haptic",
  "sentTimestamp": 1730000000000,
  "epochTimestamp": 1790000000000,
	"relativeTimestamp": 500,
  "payload": {
    "intensity": 0.75,
    "durationMs": 600,
    "transitionMs": 0
  }
}
```

| Payload field | Type | Required | Description |
| --- | --- | --- | --- |
| `intensity` | number | Yes | Normalized haptic strength 0-1. |
| `durationMs` | integer | Yes | Length of the haptic response. |
| `transitionMs` | integer | No | Time to transition from the haptic intensity to this event's intensity. |
