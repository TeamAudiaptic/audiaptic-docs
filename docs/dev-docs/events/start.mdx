# Start Event

A `start` event indicates when a performance should start. Other event's relative timestamps are based on when the Start is executed. Start has no payload.

```json
{
  "schemaVersion": "1.0",
  "eventId": "00000000-0000-0000-0000-000000000000",
  "sequence": 43,
  "type": "start",
  "sentTimestamp": 1730000002000,
  "epochTimestamp": 1790000000000
}
```
