# Torch Event

A `torch` event turns the device flashlight (rear-camera torch) on for a fixed interval. It does not capture camera video or images.

```json
{
  "schemaVersion": "1.0",
  "eventId": "demo-torch-01",
  "sequence": 43,
  "type": "torch",
  "sentTimestamp": 1730000002000,
  "execTimestamp": 1730000002500,
  "payload": {
    "durationMs": 250,
    "transitionMs": 0
  }
}
```

| Payload field | Type | Required | Description |
| --- | --- | --- | --- |
| `durationMs` | integer | Yes | How long the torch remains on. |
| `intensity` | integer | No | Set torch brightness on supported devices. Default full brightness. |
| `transitionMs` | integer | No | Time to transition from the current intensity to this event's intensity on supported devices. |


The client must handle absent hardware or a denied camera permission gracefully.
