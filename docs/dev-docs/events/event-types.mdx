# Event Types

DAVHI supports the following event types:

- **Haptic:** starts a continuous haptic response.
- **Torch:** turns on the device flashlight.
- **Color:** shows a full-screen color.
- **Caption:** displays text.
- **Image:** displays a preloaded image asset.
- **Audio:** plays a preloaded audio asset.
- **Video:** plays a preloaded video asset full-screen.
