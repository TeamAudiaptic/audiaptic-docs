# Event Types

Each event carries one `type` and the matching payload. All baseline events apply to every device in the active session.

- [Haptic](./haptic) starts a continuous haptic response.
- [Torch](./torch) turns on the device flashlight for a fixed interval.
- [Screen](./screen) shows a full-screen color.
- [Caption](./caption) displays text in the mobile app.
- [Asset](./asset) displays a preloaded visual asset.
- [Audio](./audio) plays a preloaded audio asset.
- [Video](./video) plays a preloaded video asset full-screen.
